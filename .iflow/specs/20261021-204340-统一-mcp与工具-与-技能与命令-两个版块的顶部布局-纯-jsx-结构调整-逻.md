统一「MCP与工具」与「技能与命令」两个版块的顶部布局（纯 JSX 结构调整，逻辑零改动）：

1. **`webview/src/components/ui.tsx`** 新增三个布局原语（沿用 BTN「one home」模式）：
   - `Segmented<T extends string>`：作用域/类型分段控件，样式采用 MCP 现有形态（`rounded-lg border-border/70 bg-surface/40 px-1 py-1`，项 `px-2 py-0.5`，选中 `bg-primary/18 font-semibold text-primary`，支持 disabled/title/aria-current）
   - `SecondaryRow`：次级操作行（`mt-2 flex flex-wrap gap-3 border-b border-border/50 pb-3`）
   - `GHOST_BTN`：次级 ghost 按钮样式（收敛 McpCard 两处重复字符串）

2. **`McpCard.tsx`**：作用域分段改用 `Segmented`（顺序不变：分段 → 主操作行 添加/保存 → `SecondaryRow` 模板目录/刷新 用 `GHOST_BTN`）

3. **`AssetCard.tsx`**：顶部重排为同一模式——`Segmented`（命令/子代理/技能）置于最前 → `ToolbarRow` 主操作（新建 + 错误/冲突/已保存回显）→ `SecondaryRow` ghost「刷新」→ 列表（移除原先嵌在列表里的分段）

统一后的视觉层级：轴选择器 → 主操作行 → 次级操作行 → 列表，两版块一致；分段控件样式单一来源。

验证：`cd webview && npx tsc --noEmit` + `npm run typecheck`、`npx vitest run test/mcp-card.test.tsx test/assets-card.test.tsx test/cards-shortcuts.test.tsx test/ui-settings.test.tsx`、`npx vite build webview`、frontend-tester 在 mock webview 逐版块点击复核。
