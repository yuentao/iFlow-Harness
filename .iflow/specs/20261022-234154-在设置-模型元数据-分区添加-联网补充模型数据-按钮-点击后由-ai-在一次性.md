在设置「模型元数据」分区添加「联网补充模型数据」按钮：点击后由 AI 在一次性 CLI 会话中用 web_search 检索市面最新模型资料 + 当前 API 配置的 live /models 模型列表，输出 JSON 信封，host 校验后追加到上下文窗口覆写 / 成本单价 / 思考规则三个表（永不覆盖已有条目、绝不伪造数值）。

实施步骤：
1. `shared/model-metadata.ts`（新文件，纯逻辑）：提示词构造、JSON 信封解析（围栏/前缀容忍、字段校验、超限丢弃）、去重合并计划（normalizeModelId 去重、思考规则仅追加 true、已有 pattern 覆盖则跳过）、模型选择（live 列表验证，陷阱 #25）。
2. `shared/messages.ts`：WebviewToHost 加 `fetchModelMetadata` / `cancelModelMetadata`；HostToWebview 加 `modelMetadataState`（searching/done/error/idle + added 计数 + error）。
3. `src/acp/client.ts`：`prompt(request, timeoutMs?)` 允许单次调用超时覆写（默认仍无限）。
4. `src/panel/panel.ts`：
   - 消息路由两个新 case；独立 busy lane（不与 enhance/knowledge 互斥）。
   - 一次性会话：`newSession` → 强制 `set_mode default` → `set_model`（live 验证过的模型）→ prompt（180s 天花板 + 75s idle watchdog + 可取消）。
   - 守卫：该会话的 session/update 不进转录（只累积 agent_message_chunk 文本作信封来源）；permission 一律自动拒绝（web_search 只读不请求权限）；questions/plan-exit 自动回空/拒绝；防止泄漏进用户会话。
   - 结果解析 → `planMetadataAdditions` → `writeUserSetting` 追加三份表 → `postHostSettings()` 刷新面板；toast 报告计数/错误；结束清理会话文件（`acpSessionFilePath` unlink，尽力而为）。
5. `webview/src/store.ts`：`modelMetadata` 状态 + `modelMetadataState` 消息处理 + `createMockHost` 模拟（searching → 追加示例条目 → done；cancel 可中断）。
6. `webview/src/components/SettingsModal.tsx`：disclosure 顶部 ActionRow 按钮（Globe 图标；检索中 Loader2 spinner + 「停止检索」；错误 inline caption）+ 说明 Hint；`i18n.ts` 新键；`l10n/bundle.l10n.en.json` 补 host 文案英文。
7. `test/model-metadata.test.ts`：提示词、解析（围栏/前缀/无效→空、字段校验、80 上限）、合并去重（大小写/前缀/已有 pattern 覆盖/false 不追加）、pickMetadataModel 链。
8. 验证：`npx vitest run test/model-metadata.test.ts`、`npm run typecheck`、`cd webview; npx tsc --noEmit`、`npx vite build webview`；frontend-tester 在 mock webview 点击验证按钮流（busy→done、追加显示、停止）。
