## 目标
子会话完全由智能体委派协议产生，移除看板上的「新建子会话」入口（按钮 + 派发表单），子会话的创建只保留 agent 侧 `super-agent` 代码块通道；看板保留状态/中断/合并/清理/作答等管理动作。

## 改动清单

1. `webview/src/components/SuperAgentBoard.tsx`
   - 删除「新建子会话」Button、派发表单（标题/任务说明/派发）、`composing/title/task` 状态与 `submit`
   - 空看板判断改为 `list.length === 0`；移除随之无用的 `Plus / Field / TextInput / TextArea` 导入
   - 组件注释改为说明「子会话由智能体委派产生，看板只做管理」
2. `shared/messages.ts`：`superAgent` 消息去掉 `"spawn"` 动作与只服务于它的 `title / task` 字段，注释写明「子会话只由智能体委派协议创建」
3. `src/panel/panel.ts`：`handleSuperAgentAction` 删除 `case "spawn"` 分支（其余管理动作不动）
4. `webview/src/store.ts`：mock 宿主删除 superAgent 的 `spawn` 分支
5. `webview/src/i18n.ts`：删除仅服务于该表单的文案键（新建子会话 / 任务标题 / 两条占位示例 / 任务说明）；「派发」保留（Composer 的委派模式仍在用）
6. 文档同步：`AGENTS.md` Super Agent 条目去掉「UI 另有『新建子会话』按钮兜底」并改为「子会话只由智能体委派产生」；`CHANGELOG.md` 2.2.0 条目同步（当前在 beta 分支未合入 master/release，故直接改 2.2.0 摘要，不新增版本号）

## 明确不动的部分
- 智能体委派通道：`scanSuperDirectives`（agent 输出 `super-agent` 代码块即派发）保持不变
- 主会话 streaming 时用户 Enter 直接派发为子会话（Composer 显示「派发」）保持不变——这是「主会话只做委派」的既定行为，不是手动新建入口
