# 设置面板布局归一化（组件化）

## 新增 `webview/src/components/ui.tsx` 布局原语（沿用 BTN 常量「one home」模式）
- `Hint`：说明段规范 `text-ui-label leading-relaxed text-muted-foreground/85`
- `ActionRow`：操作行 `flex flex-wrap items-center gap-1.5`（堆叠偏移由调用点 mt-* 或父级 space-y 决定，避免同属性类串覆盖）
- `ToolbarRow`：带分隔线工具行 `mt-2 flex flex-wrap items-center gap-2 border-b border-border/50 pb-3`
- `FieldLabel`：表单 caption `text-ui-label text-muted-foreground` + 可选必填星号
- `Field`：`<label className="flex flex-col gap-1">` + caption + 控件（className 支持并排 flex-1）
- `space-y-2/3` 保留字面量（既定约定，不组件化）

## 调用点归一（5 个设置卡片，纯 JSX 结构调整，逻辑零改动）
- **ApprovalPolicyCard**：4+2 表单 label→`Field`；操作行→`ActionRow`；说明段→`Hint`
- **McpCard**：2 toolbar 行→`ToolbarRow`；底部说明 `mt-3 text-ui-body`→`Hint mt-2`（14px→13px 轻微收敛）；编辑表单说明段→`Hint`；名称 label→`Field`；表单 div 行内 span→`FieldLabel`
- **AssetCard**：toolbar→`ToolbarRow`；说明段→`Hint`；4 label→`Field`；操作行→`ActionRow`
- **SettingsModal**：4 处行内说明→`Hint mt-1`；API 表单 4 label→`Field`；保存行/预设行/居中行→`ActionRow`；可导入凭据说明→`Hint`
- **MemoryCard**：编辑页提示与知识说明段→`Hint`
- 豁免项（光学间距、分段控件、行内 micro note）不动

## 验证
1. `npm run typecheck`（host+webview）+ `cd webview && npx tsc --noEmit`
2. `npx vitest run`（重点 mcp-card/assets-card/cards-shortcuts/ui-settings 等组件测试）
3. `npx vite build webview` + 产物 grep
4. `node scripts/serve-webview.mjs 8791` 浏览器逐 tab 目视复核 + frontend-tester 验证

预期视觉：说明段统一 13px/muted-85、操作行 gap 统一 6px（McpCard/AssetCard 底部说明 14→13px、个别居中行 gap 4→6px，轻微收敛）。
