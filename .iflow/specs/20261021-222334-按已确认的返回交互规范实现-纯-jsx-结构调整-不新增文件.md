按已确认的返回交互规范实现（纯 JSX/结构调整，不新增文件）：

1. **McpCard.tsx**
   - header 上报 effect 新增 `catalogBrowse` 分支：浏览模板目录时壳层 header 显示「模板目录」+ 返回箭头（依赖数组加 `catalogBrowse`）。
   - SecondaryRow 目录按钮固定文案「模板目录」（只负责打开，不再翻转成「返回列表」）；浏览期间隐藏 ToolbarRow（添加/保存）与 SecondaryRow（模板目录/刷新），正文只保留作用域行 + 目录列表。
   - 删除详情页底部 `Check` 图标 + 「返回」按钮（返回走 header 箭头），同时移除不再使用的 `Check` import。

2. **AssetCard.tsx**
   - 删除详情页底部 `Check` + 「返回」按钮，保留「编辑」（仅在内容加载完成后显示）；移除 `Check` import。

3. **SettingsModal.tsx + ui.tsx**
   - `ModalShell` 新增可选 `onEscape` prop（Esc 走它而非 onClose，保持非可关闭弹窗吞 Esc 的现有纪律；deps 加 onEscape）。
   - SettingsModal 传 `onEscape`：子页打开时 Esc = 返回上一层，否则关弹窗。
   - 侧栏键盘导航：子页打开时 `ArrowLeft` 触发返回而非切换 tab（ArrowUp/Down 维持 tab 导航）。

4. **test/mcp-card.test.tsx**
   - 详情子页测试改为通过 header 回调 `back()` 返回（断言 header 上报 null），不再 `click("返回")`。

5. **验证**
   - `cd webview; npx tsc --noEmit`；`npx vite build`（webview 产物）；`npx vitest run test/mcp-card.test.tsx test/assets-card.test.tsx test/cards-shortcuts.test.tsx`。
   - frontend-tester 在 mock webview（npm run webview:serve）逐项验证：目录浏览 header 返回、详情返回、Esc/ArrowLeft 行为。
