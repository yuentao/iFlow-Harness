1) 设置面板：初始焦点改到当前侧栏项（不再落到上下文窗口覆写输入框），切换 tab 时滚动容器回顶。
2) 设置视觉：统一字号层级（分组标题/行标签/说明/控件），加大行内边距与分组间距；把 MCP/资产/账户等长列表的主操作（保存、新增、刷新）移到列表上方或底部操作条，降低信息密度（模型元数据收进可折叠区）。
3) 会话历史下拉：加宽菜单、放大置顶/归档/删除图标与点击区，行高与字号同步提升；新增重命名（内联输入 + 铅笔按钮）。
4) 重命名链路：shared 增加纯函数，messages 增加 renameSession，host 更新 workspaceState 索引并同步 transcript 标签，mock host 同步支持。
5) 全局滚动条：宽度 10→8、颜色更淡，默认透明，滚动时（html.is-scrolling）才显示，停止滚动约 800ms 后隐藏。
6) 验证：npm run typecheck、webview tsc、npm test、webview build，并用 frontend-tester 在 mock host 下检查设置面板与会话下拉。
