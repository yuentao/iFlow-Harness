## 诊断

当前 `InjectedContextCard`（webview/src/components/MessageList.tsx:1102）两个问题：

1. **tag 过多**：header 用 `flex-wrap`，chip 一多（MCP 未连接 / MCP 项目级 出现时）就换行成 2–3 行 chip 堆，卡片头部膨胀、视觉噪声。
2. **内容过多**：展开后每个注入项的全文 `pre` 立即挂载（违反陷阱 #27 懒挂载纪律），多来源时展开卡极高、DOM 重。

## 方案（沿用既有设计语言）

**Header 单行化 + 溢出收纳**
- header 改 `flex items-center`（不再 wrap）：caret / 「自动注入」/ ≈tokens 保持 `shrink-0`，chip 行改为 `min-w-0 flex-1 overflow-hidden` 的独立容器。
- 新增 `InjectedChipRow`：用一个不可见全宽克隆行（`opacity-0 absolute`）量各 chip 自然宽度，ResizeObserver 监听容器宽度；放不下的尾部 chip 收进 `+N` chip（预留 ~44px），完整清单在展开正文里。jsdom（offsetWidth 0）退回全显示，不影响现有测试。

**正文逐项折叠 + 懒挂载**
- 新增 `InjectedBody`：短正文（<3 行）照旧内联；长正文默认折叠，caret +「查看内容」toggle，`openedOnce` 首次打开才挂载（与工具输出卡同一物种）。
- 注入项行（memory/context-file/knowledge）与 `SystemPromptSections` 的各 section 都改用 `InjectedBody`；MCP 行与 core 提示词行（只显示字节数）不变。
- 展开卡从「全文堆叠」变成紧凑条目列表，逐项按需展开。

**i18n**：`webview/src/i18n.ts` 加 `查看内容` / `其余注入类别见展开详情` 英文键。

## 验证

1. `cd webview && npx tsc --noEmit` + `npx vite build`（webview 构建产物）
2. `npx vitest run test/cards-shortcuts.test.tsx test/session-state.test.ts test/ui-kit-guard.test.ts`（定向）+ `npm run typecheck`
3. frontend-tester 用 mock webview 实测：多 chip（含 MCP 未连接/项目级）时 header 保持单行且出现 +N；展开后条目逐项折叠、点击「查看内容」懒挂载；窄屏无横向溢出。
