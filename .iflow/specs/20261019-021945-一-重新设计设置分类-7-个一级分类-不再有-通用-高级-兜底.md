## 一、重新设计设置分类（7 个一级分类，不再有「通用/高级」兜底）
1. **账户与模型**（原 API 配置）
   - API Profile、凭据编辑、CLI 凭据导入
   - 模型上下文窗口覆写 `contextWindowOverrides`
   - 成本单价 `costTable`
   - 推理能力规则 `thinkingModelRules`（JSON 编辑器）
2. **对话**
   - 下一步建议、自动压缩上下文、自动生成标题、自动提取记忆
   - 全部按「回合结束后行为」归组
3. **外观与交互**
   - 主题、字号、密度、极光强度
   - 提示音、系统通知
   - 快捷键表
4. **权限与审批**
   - 面板默认权限模式 `defaultMode`
   - CLI 默认审批模式 `approvalMode`（标注重启生效）
   - 审批规则（现有策略表）
5. **MCP 与工具**
   - MCP 服务器管理
   - 明确说明：MCP 配置在 `~/.iflow/settings.json`，不随 VSCode 设置同步
6. **记忆与知识**
   - 现有全局/项目记忆文件、知识库
7. **运行与数据**
   - 启动与会话：`warmStart`、`autoOpenPanel`、`restoreLastSession`
   - CLI 运行时：`nodePath`、`language`
   - 检查点与存储：`checkpoints`、`checkpointMaxFiles`、`checkpointMaxFileMB`、`checkpointMaxTurns`、`checkpointMaxSizeMB`、`checkpointDir`
   - 同步与原始设置：写入用户 settings.json 的说明 +「在 VSCode 设置中编辑…」

所有 26 个 `iflow.*` 配置都映射到以上分类；新增 `iflow.theme`（auto/light/dark）。

## 二、布局与排版重构
- 设置弹窗单独加宽到 `min(680px, 100vw - 32px)`、高 `min(640px, 86vh)`（新增 `settings-modal` 类，不影响 OnboardingWizard / MemoryReviewDialog）。
- 左侧导航 150px，窄屏折叠为可横向滚动的顶部 tab。
- 用 `SettingsGroup`（组标题 + `divide-y` 行）替代「每行一张卡」的卡片墙；行标题 12.5px、说明 11.5px、组标题 11px 大写，统一内边距与间距。
- 控件右对齐；窄宽度下选择器/输入框自动堆叠，开关保持右侧。
- 新增 `NumberRow` / `TextRow`（blur/Enter 提交）、`LinesRow`（每行一条）、`JsonRulesRow`（校验后「应用」）、`RangeRow`（拖动预览、松手提交）。
- 底部固定：`flex-wrap`，保留「重启 CLI」与「在 VSCode 设置中编辑…」，宽屏右侧显示「已写入用户 settings.json」。
- 删除重复解释段落，文案并入说明。

## 三、数据链路
- `shared/messages.ts`：`HostSettingsUi` / `setHostSettings` 扩展为全量字段（含 `theme`、`ThinkingModelRuleUi`、数组）。
- `src/panel/panel.ts`：`postHostSettings` 读取并规范化全部配置；`setHostSettings` 校验后逐项写 `ConfigurationTarget.Global`；任意 `iflow.*` 变更重推。
- `package.json` + 两个 nls：新增 `iflow.theme`。
- 主题去 localStorage：首次收到 `hostSettings` 时迁移旧 `iflow-theme` 到配置并清除；`App.tsx` 由 `hostSettings.theme` + `editorTheme` 计算明暗。
- `store.ts`：扩展默认值、mock host、`applyHostMessage` 映射。
- `ApprovalPolicySection` 增加 `defaults` 插槽，编辑规则时隐藏默认模式组。
- `SettingsModal` 的 `SettingsTab` 改为 `api | chat | appearance | policy | mcp | memory | runtime`。
