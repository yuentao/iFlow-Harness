把提示词从「随包发布的可读 .md 文件」改成「构建期内联进扩展 bundle」，并让唯一必须落盘的 system-prompt 写到扩展自己的 storage 目录（不在扩展安装目录里）。

1. `prompts/index.ts`:改为静态 `import text from "./x.md"`（14 个模板），移除 `node:fs` 读取、`setPromptDir`、`promptFile`；对外 API（`loadPrompt`/`renderPrompt`/`loadPromptKeys`/`promptKey`）不变。
2. `prompts/md.d.ts`(新增，仅类型声明):`declare module "*.md"`；`webview/tsconfig.json` 把它纳入 include（webview 编译 `../shared`，其中 builders 会解析到 prompts）。
3. `esbuild.mjs`:加 `loader: { ".md": "text" }`，模板文本打进 `dist/extension.cjs`。
4. `vitest.config.ts`:加一个 `.md` → 文本默认导出的插件，让单测走同一契约。
5. `src/panel/panel.ts`:删掉 `setPromptDir(...)`；spawn 前把 `loadPrompt("system-prompt")` 写入 `storageUri ?? globalStorageUri`/`system-prompt.md`（走 `vscode.workspace.fs`，内容未变则不重写），写入失败就不设 `IFLOW_SYSTEM_MD`（CLI 对缺失文件会抛错）。
6. `.vscodeignore`:`prompts/**/*.ts` → `prompts/**`；新增 `dist/**/*.map`（现有 map 内嵌全部源码 sourcesContent，7.6MB，目前随包发布——不排除的话内联的提示词会换个地方泄漏）。
7. `AGENTS.md`:更新「system-prompt.md 随 VSIX」那句描述。

验证:`npm run typecheck`(host+webview) → `npm test` → `npm run build` → `npx vsce package --no-dependencies --output .tmp-check.vsix` 并检查包内没有 `prompts/` 与 `.map`，然后删除临时包。

诚实说明:内联后提示词字符串仍存在于 `extension.cjs`（可被 grep 还原），只是不再以可读文件形式出现在扩展目录。若需要连 bundle 也不易读，可后续加 base64/混淆（本轮不做）。
