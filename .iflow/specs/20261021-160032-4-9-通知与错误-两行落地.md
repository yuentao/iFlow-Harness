## 4.9 通知与错误 — 两行落地

### 一、四套通知统一为三层（webview）
| 通道 | 现状 | 处置 |
| --- | --- | --- |
| Composer 内联 note | 已 `notify` → 共用 toast stack | 不改（已统一） |
| host toast | 底部 toast stack | 不改生命周期（倒计时 toast 须活到 host deadline） |
| ErrorToast | 悬浮盖住转录首条、四控件挤一行 | 改 `ErrorBanner`：header 下方 inline banner，单行摘要 + 「重试」主操作 + 「详情」；复制/advice 收进详情面板 |
| auth banner | composer 上方 | 移到同一 banner 层（header 下方） |

### 二、限流倒计时 toast 与「生成中」pill 合并
- `MessageList.tsx`：新增 `countdownToast` 选择器；`streaming && !compressing` 时倒计时 toast 合并进 sticky pill（消息 + 实时 `Ns`），并从 toast stack `skipToastId`；压缩告警合并保留，同时存在时倒计时优先。
- 抽共享 `CountdownSeconds`（锚定 host 绝对 deadline），toast pill 与合并 pill 共用，消除双计时漂移。

### 三、host 侧
不改（`src/panel/panel.ts` 倒计时 toast 语义已是绝对 deadline，合并属呈现层）。

### 四、验证
`cd webview && npx tsc --noEmit` → `npx vite build webview` → `npm test` → `node scripts/serve-webview.mjs`（8791）+ frontend-tester 实测 banner 层与合并 pill。
