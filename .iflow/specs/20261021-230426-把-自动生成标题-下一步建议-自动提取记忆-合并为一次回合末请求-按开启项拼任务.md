把「自动生成标题 / 下一步建议 / 自动提取记忆」合并为一次回合末请求（按开启项拼任务，一次网关调用）。

## 现状
三条独立 lane、三次请求：
- `panel.ts:2171 maybeGenerateAiTitle` → `runInternalPrompt`（`internalPromptBusy`）
- `panel.ts:2228 generateNextStepSuggestions` → `completeInternalPrompt`（`nextStepBusy`）
- `memory/service.ts:430 maybeExtract` → `runMemoryPrompt`（`memoryPromptBusy`）

## 改动
1. **新增 `shared/turn-followup.ts`（纯逻辑）**
   - `buildFollowupPrompt(input)`：只拼入已开启且符合条件的任务节（标题节 / 下一步节 / 记忆节），末尾给出单一 JSON 信封键规范（`title` / `nextSteps` / `facts`），沿用内部提示词纪律（声明纯文本任务、禁工具）。
   - `parseFollowupResponse(raw, requested, max)`：先按外层 JSON 对象解析；解析失败退化为按键挖取（平衡括号挖数组、正则挖字符串）。缺项一律降级为 `null`/`[]`，绝不伪造。`memoryRaw` 原样透传给 `parseCandidates`。

2. **`shared/session-state.ts`**：从 `parseNextStepSuggestions` 抽出 `sanitizeSuggestions(values, max)`（去列表标记、去重、≤120 字、截断），两处复用。

3. **`src/memory/extract.ts`**：`buildExtractionPrompt` → `buildExtractionConversation(blocks, limits)`（只产对话节选行），提示词正文移入合并提示词；`parseCandidates`/`normalizeFact` 不变。

4. **`src/memory/service.ts`**：删除 `maybeExtract` 与 `extractBusy`、`runPrompt` 选项，改为：
   - `isExtractionEligible(sessionId, blocks)`（开关 / 会话 / 2 分钟限流 / 有内容）
   - `buildExtractionInput(blocks)` → `{conversation, existingFacts}`
   - `beginExtraction()`（记限流时间戳 + 发「正在提取」pill）/ `finishExtraction(toastId)`
   - `applyExtractionResult(raw, sessionId, existingFacts)`（解析候选 + 候选 toast）
   限流只在请求真正发出时消耗，被门控挡掉时不占用。

5. **`src/panel/panel.ts`**
   - 删除 `maybeGenerateAiTitle`、`generateNextStepSuggestions`、`runMemoryPrompt`、`memoryPromptBusy`、`nextStepBusy`。
   - 新增单一 `followupBusy` lane 与 `runTurnFollowup(sessionId, { allowTitle, conversationTasks })`：逐任务判定（标题：首轮 + 机械标签 + 未尝试过；下一步/记忆：跳过压缩轮；各自开关），拼 prompt，一次 `completeInternalPrompt`，超时/空闲取各任务上限的最大值。
   - 分发保持原有守卫：标题写回前复核会话与标签仍是机械形式；下一步保持引用锚 + 块数 + status 锚定与中途关闭开关复检；记忆按 sessionId 丢弃过期结果。
   - `enhance` 在飞时整体跳过（不登记标题 id，下一轮重试），保持「一次内部请求」纪律。
   - `sendPrompt` / `regenerate` 的三处调用点改为一次调用（regenerate 不带标题任务，与现状一致）。

6. **测试**
   - 新增合并请求用例（`test/internal-prompt.test.ts`）：只开一项/多项时只发一次请求、prompt 含对应节、信封解析分发、压缩轮不触发、限流不占用。
   - `test/memory-extract.test.ts`：改用 `buildExtractionConversation`。
   - `test/memory-service.test.ts`：两条 `maybeExtract` 用例改新 API。
   - `test/context-autocompress.test.ts`：门控用例改为断言 `runTurnFollowup` 的 `conversationTasks` 参数。
