按 milestone 14 §4.5 落地审批 / 提问 / Plan 卡，**保持现有设计语言**（语义字号 token `text-ui-*`、`BTN`/`BTN_SM` 基元、`acrylic`+`glow-ring` 待处理卡材质、现有 rounded/spacing token；不新增 arbitrary `text-[Npx]`、不引入新视觉系统）。

## 1. `webview/src/components/ui.tsx` — CountdownBar 渐进披露
- 新增可选 `quietLabel`。`remaining > 60s` → 一行 muted caption `t("约 {0} 分钟后{1}", 分钟, quietLabel)`（no bar、no per-second jitter）；`≤60s`才渲染现有 bar + `mm:ss`（warning/destructive 色阶保留）。
- 三卡调用各自 label：审批 / Plan → `t("自动拒绝")`（已有 en "Auto-deny"），提问 → `t("自动继续")`。

## 2. `ApprovalCard.tsx`
- **安全焦点（P0）**：初始 focus 不再 land on allow。新增 `data-autofocus` 落在 reject option（存在时）否则「取消」按钮；mount-focus 改为 `querySelector("[data-autofocus]")`。允许/始终允许 只能通过 Tab 或点击。
- **标题写动作（P1）**：header 现有 `iFlow 请求执行工具` 变成 eyebrow `text-ui-micro text-muted-foreground` 的 `iFlow 请求执行` + 主行 `{动词} {primary.path ?? toolName}`（动词按 `toolKind`：读取/写入/编辑/搜索/执行/删除/移动/读取网页，fallback 执行）。Body 段落里去掉 toolName 的 `code` chip（信息已在 heading），保留 `approval.title` 全文 + FileRef + diff。
- **选项文案（P1）**：按 `kind` 映射本地ized label（`允许一次 / 始终允许 / 拒绝 / 始终拒绝`），unknown kind 保留 CLI 原文；CLI 原文放 `title` attr；`aria-label` 用 display label。
- **reject/cancel 去重复（P1）**：有 reject option → 不 render 额外「取消」；`Esc` 与 `n` 走 `rejectOption.optionId`（无 reject 才 `null`）。
- **去重复快捷键（P1）**：HelpTip 里删 mono 行（操作行 `ml-auto` span 保持，符合项目 convention）。
- **a11y（P1）**：`role="alertdialog"` 用 `aria-labelledby`(action heading)+`aria-describedby`(title paragraph)，`useId()`。

## 3. `QuestionCard.tsx`
- custom `<input>` `Enter` → 只确认/收起该输入（placeholder 已读「回车确认」）；整卡提交 = `Cmd/Ctrl+Enter` 或「提交回答」按钮。
- 「跳过」→「不回答并继续」（三级 ghost button，aria-label 同步）。
- alertdialog `aria-labelledby`/`aria-describedby`。

## 4. `PlanExitCard.tsx`
- 初始 focus → 拒绝计划（`data-autofocus`）；批准需 Tab/点击。
- editing 态：第三按钮 label 变「保存并重新规划」（same action，verb-first），非 editing 保持「重新规划」；删除 editing-mode 的重复说明 paragraph（tooltip 保留单一 home）。
- tooltip 里删 mono shortcut line（操作行保持）。
- alertdialog `aria-labelledby`/`aria-describedby`。
