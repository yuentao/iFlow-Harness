## 升级 MCP 配置编辑器：表单化配置替代裸 JSON

当前状态：MCP 模板目录 + 表单化安装已存在（F4），但 MCP 服务器添加/编辑编辑器仍是裸 JSON textarea（`McpCard.tsx` 的 `editing` 视图）。skills/agents/commands 资产可视化管理（AssetCard 三组 + 新建/编辑/删除）已实现且测试过，只需回归验证。

### 改动 1：`webview/src/components/McpCard.tsx`
- 新增纯 helpers：`parseConfig`（JSON→对象）、`configWithField`（command/url 字符串字段，空值即删键）、`configWithArgs`（每行一个 arg）、`configWithMap`（`KEY=VALUE` 每行，首个 `=` 分列）— 每次 field 编辑把 parsed 对象 merge 回，**未知字段保留**（description/type/_lastModified 等）
- `MCP_FORM_KEYS` 常量；编辑器视图改为表单：
  - 名称 input（unchanged）
  - 命令（本地 stdio）input + 启动参数（每行一个）textarea + 环境变量（KEY=VALUE，每行一个）textarea
  - 服务 URL（远程 http/sse）input + 请求头（KEY=VALUE，每行一个）textarea
  - 额外字段保留：xxx 提示行（unmanaged keys 透明保留）
- 「添加」skeleton 改 `{}`（表单字段空）
- 「完成」validation：现有 name/JSON-object 校验 + 新 transport 校验（exactly one of command/url；both → 报错，neither → 报错）
- catalog install note 改「安装只把模板本地草稿，点击「保存」才写入文件。」（去掉「直接编辑 JSON」clause）
- Entry doc comment 更新

### 改动 2：`webview/src/i18n.ts`
- 移除旧「配置 JSON（stdio：…）」键；新增 8 键（命令/启动参数/环境变量/服务 URL/请求头/both/neither/额外字段保留）+ 新 install note 键

### 改动 3：`test/mcp-card.test.tsx`
- catalog install 用例：args textarea 断述 `J:\demo`（form 视图，每行一个）
- 新增 3 用例：form 编辑 command/args/env 保留 unknown keys（payload deep-equal）；neither command nor url 即「完成」blocked；both command and url 即「完成」blocked
- 资产/其他用例 untouched

### 验证（按项目流程）

3. `npm run typecheck`（host）+ `npm test`（full，仅 known Windows EPERM symlink 用例失败）
4. Browser mock validation（vite build + static server）：MCP tab 表单编辑器（模板 install → form fields → save）+ 技能与命令 tab 回归 + console clean
